# FIDELITY GATES — ORYZO EXPERIMENT

Cocher uniquement lorsqu'un test réel et sa preuve sont disponibles.

## Gate 0 — Import et build
- [ ] Importer sur la branche experiments/oryzo-reference, sans toucher à main.
- [ ] La preview indique ORYZO Reference et n'affiche pas le précédent LOISEAU LAB.
- [ ] npm install, npm run build et npm run lint sans erreur bloquante.
- [ ] OBJ MIT effectivement chargé, canvas visible, pas d'erreur d'asset.
- [ ] Le modèle fonctionne aussi si le mouvement réduit est activé.

## Gate 1 — Baseline vraie
- [ ] Source à 1440×900, 768×1024, 390×844.
- [ ] Charger le site après intro/preloader.
- [ ] FRAMES=64 ou plus (un audit indépendant indique environ 64 écrans).
- [ ] DOM et style repérés; scroll et positions exactes.
- [ ] Assets inventory JSON rempli, URL de chaque fichier, type et status.
- [ ] Rapports console et requêtes réseau complets.
- [ ] Captures d'interactions menu, produit, hand/canvas, Smart Flip, vidéo et galeries.
- [ ] Captures non commitées ou publiées sans droits.

## Gate 2 — Visual/motion reconstruction
- [ ] Intro loader précis.
- [ ] Hero avec assets autorisés, composition exacte et caméra.
- [ ] Source de vérité des couleurs #100904 #FFEDD7 #DC5000 #445231.
- [ ] Typographie de substitution signalée tant que licence non acquise.
- [ ] Coaster 3D persistant sans pop/swap lors du scroll.
- [ ] Phases AI-hand, wearable, photo wall, magazine.
- [ ] Lift, thermal, roundness, zoom, smart flip, anti-slip, sustain.
- [ ] Reviews, product picker, paper et contact.
- [ ] Toutes les micro-interactions documentées (états hover/click/touch).
- [ ] 60 FPS ou budget perf adapté, avec mesure en conditions réelles.
- [ ] Reduced-motion, clavier et responsive testés.

## Gate 3 — Vérification
- [ ] Captures locales comparables à la source, même viewport/DPR.
- [ ] reports/comparison.md généré et interprété.
- [ ] Aucune erreur réseau locale inexpliquée ni erreur JS critique.
- [ ] Contrôle différences typographiques, placements, cadrage, motion.
- [ ] Liens, boutons, overlays, scroll interactions fonctionnels.
- [ ] Écarts / ressources indisponibles consignés honnêtement.
- [ ] Aucun chiffre d'identité à 100 % inventé.

## Publication
- [ ] Pas de publication publique de copie de marque sans autorisation.
- [ ] Contenus/proprietary assets remplacés ou explicitement licenciés.
- [ ] LOISEAU commence **après** validation du moteur d'étude, dans un projet distinct.
